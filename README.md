## 📌 Guidelines for a Great Issue

To help us understand and resolve your feedback faster, please include:

- **A clear and descriptive title.**
- **The environment:** operating system, version, and desktop session.
- **Steps to reproduce** the problem (for bugs).
- **Expected vs. actual behavior.**
- Any relevant **logs, screenshots, or configuration** files (be careful not to share sensitive data).

## 📣 Not Sure Where to Report?

If you're unsure which repository your feedback belongs to, feel free to open an issue on the main **argvus** repository and our team will help redirect it.
